## Inputs

- **Required:** Your topic, script and facts to preserve.
- **Optional:** Your current talking-head video with its original audio for the native presenter workflow.
- **Optional:** The current voice recording or your narration preference for this production.
- **Optional:** A transcript or SRT matching the current narration/video.
- **Optional:** Your photos and a title for this work.
- **Optional:** A licensed music track or your preference for music in this production.

## Begin production

1. Continue with the topic, script and materials already supplied; ask only for missing required inputs. Draft suitable copy when the user requests a random example.
2. Obtain the corresponding .motion through the exact template page above. If sign-in is required, the user completes it on the website and supplies the package or local path. If download is pending, report the current status and continue preparing content.
3. Extract or load the actual package as documented. Read its README, first-read entry and referenced guide, then inspect parameters, dependencies and license. The package guide defines the production workflow; the downloaded package's exact lock wins.
4. Check and reuse existing tools, installing only missing declared requirements. Map the user's materials to supported slots, follow the package workflow and show a real preview before continuing with feedback.
5. Use optional asset or audio services according to the actual package, input slots and current needs. A chat-only assistant can prepare content and a material list for a local runner.

## Supported scope

- The documented output is 1440 × 1920, 60 fps; default demo duration is 160.4 seconds.
- Use the actual package parameter bounds; extra materials do not automatically create extra scenes.
